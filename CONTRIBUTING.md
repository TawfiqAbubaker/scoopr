# Contributing to Scoopr

Thanks for helping improve Scoopr.

Before opening a pull request:

```sh
cargo fmt -- --check
cargo test
cargo check
```

Describe user-visible behavior changes in the pull request and include the Herdr version used for manual testing. Do not include terminal captures or fixtures containing secrets, access tokens, private URLs, or personal data.

For larger changes, open an issue first so the interaction and Herdr compatibility can be discussed before implementation.
